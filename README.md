# RedWeb Store

Демонстрационный магазин материалов для монтажа: RU/EN, две темы, поиск, категории, карточки и локальная корзина. Оплата, заказы и скачивание не подключены.

## Первая загрузка в пустой GitHub-репозиторий

Распакуйте архив и откройте папку `red-web-store` в WebStorm. В терминале этой папки:

```bash
git init
git branch -M main
git add .
git commit -m "Add RedWeb storefront"
git remote add origin git@github.com:x-m-h-m/red-web-store.git
git push -u origin main
```

Команды предполагают пустой репозиторий и настроенный SSH-доступ на вашем компьютере. Если push отклонён из-за существующих коммитов, не используйте force push: сначала клонируйте репозиторий, скопируйте туда файлы и сделайте обычный commit/push.

## Деплой

В GitHub откройте Settings → Pages → Source → GitHub Actions. Workflow `.github/workflows/pages.yml` деплоит сайт после push в main. Результат смотрите в Actions; после успеха ссылка появится в Settings → Pages. В зависимости от тарифа приватному репозиторию может быть недоступен Pages.

Предполагаемый адрес после успешного деплоя: https://x-m-h-m.github.io/red-web-store/ (сейчас не подтверждён).

GitHub Pages — отдельное размещение. GitHub push не обновляет ранее созданную версию ChatGPT Sites.

## Что редактировать

- `index.html` — структура.
- `style.css` — дизайн и темы.
- `app.js`: `products` — названия, цены, описания, категории; `dict` — переводы.

Запуск локально: открыть index.html через браузер/WebStorm или `python -m http.server 8000`, если установлен Python.

Следующие обновления:

```bash
git add .
git commit -m "Update products"
git push
```

## Реальные продажи

В текущем проекте нет сервера, панели управления, оплаты, хранения заказов или выдачи файлов. Реальный магазин требует серверной интеграции эквайринга, проверки оплаты и защищённого скачивания. GitHub Pages может размещать витрину, но сервер нужно размещать отдельно.

Не публикуйте ключи оплаты, пароли или банковские данные. Добавьте реальные файлы, лицензии, требования, сведения о продавце и условия возврата перед продажами. Для сценпаков нужны права на распространение материала.
